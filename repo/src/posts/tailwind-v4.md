# Tailwind CSS 4

Tailwind CSS 4, yeni **Oxide** engine'i ile performansı zirveye taşıyor. Artık yapılandırma dosyası yerine doğrudan CSS içinde tanımlamalar yapabiliyoruz.

## Neden Tailwind?

- Hızlı geliştirme süreci
- Ölçeklenebilir tasarım sistemi
- Zero-runtime overhead

Statik sitelerde Tailwind kullanmak, kullanılmayan CSS'lerin build aşamasında atılmasını sağlayarak en küçük boyutu sunar.
